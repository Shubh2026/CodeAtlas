# 🗺️ CodeAtlas

**AI-powered codebase exploration and visualization platform.**

CodeAtlas helps developers understand complex and unfamiliar software by visualizing code relationships and using AI to provide meaningful insights.

### 🚀 Tech Stack

* **Frontend:** React + Vite
* **Backend:** FastAPI + Python
* **AI:** Groq + Llama
* **Visualization:** React Flow

> 🚧 CodeAtlas is currently under development.
